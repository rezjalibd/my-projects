# My Projects — پنل مدیریت پروژه‌ها

پنل شخصی رضا جلیلی برای مدیریت پروژه‌ها — همان «My Projects» داخل اپ موز،
حالا از طریق وب هم در دسترس است.

- **آدرس عمومی:** https://rezjalibd.github.io/my-projects/
- **ورود:** با رمز پنل (رمز را از رضا بگیرید — رمز در هیچ فایلی، لاگی یا همین ریپو ذخیره نشده است).
- **معماری:** فرانت‌اند استاتیک روی GitHub Pages + API روی Cloudflare Worker به
  نام `my-projects-api` + داده‌ها در Cloudflare KV (namespace به نام `MY_PROJECTS`).
  هیچ داده‌ای داخل ریپو یا مرورگر ذخیره نمی‌شود؛ همه خواندن/نوشتن از طریق Worker انجام می‌شود.
- **فیلدهای هر پروژه:** نام، کارفرما، وضعیت، تاریخ تحویل شمسی، مبلغ، تسویه، قدم بعدی،
  چک‌لیست کارها، یادداشت‌های تاریخ‌دار، لینک‌ها — به‌علاوه ویزارد ۶ مرحله‌ای «پروژه جدید».
- **ظاهر:** دقیقاً مثل اسپیس «My Projects» داخل اپ موز — همان رنگ‌ها،
  کارت‌ها، ویزارد ۶ مرحله‌ای تمام‌صفحه و همان فونت.
- **فونت‌ها:** Vazirmatn (متغیر، وزن ۱۰۰ تا ۹۰۰) — همان فونت اسپیس.
  فایل‌های woff2 به صورت base64 داخل `styles.css` جاسازی شده‌اند، چون
  GitHub فقط فایل متنی پوش می‌کند و فایل باینری فونت را نمی‌شود مستقیم
  پوش کرد. سورس Worker در `worker/worker.js` هست.
